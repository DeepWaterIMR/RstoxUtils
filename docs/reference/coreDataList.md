# List of core data columns by data type in NMD Biotic data

List of core data types used in the
[`processBioticFile`](https://deepwaterimr.github.io/RstoxUtils/reference/processBioticFile.md)
function

## Usage

``` r
coreDataList(type)
```

## Arguments

- type:

  character string specifying the data type. Alternatives: "mission",
  "fishstation", "individual", "catchsample", or "agedetermination".

## Value

Returns a character vector of core data types for a given data type.
