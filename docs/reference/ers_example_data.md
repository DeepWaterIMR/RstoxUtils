# Example ERS data

Example ERS data for beaked redfish. Use the
[`extractERS`](https://deepwaterimr.github.io/RstoxUtils/reference/extractERS.md)
function to produce similar data.

## Usage

``` r
ers_example_data
```

## Format

A tibble

## Source

Norwegian Directorate of Fisheries (<https://www.fiskeridir.no/>)
