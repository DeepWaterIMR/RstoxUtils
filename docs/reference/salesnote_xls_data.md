# Example historic sales note data extracted from Excel sheets on IMR server

Example sales note data for beaked redfish. Use the
[`readSluttseddelXLS`](https://deepwaterimr.github.io/RstoxUtils/reference/readSluttseddelXLS.md)
function to produce similar data.

## Usage

``` r
salesnote_xls_data
```

## Format

A tibble

## Source

Institute of Marine Research (<https://imr.no>) and Norwegian
Directorate of Fisheries (<https://www.fiskeridir.no/>)
