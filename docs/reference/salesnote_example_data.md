# Example sales note data downloaded through the API

Example sales note data for beaked redfish. Use the
[`downloadLandings`](https://deepwaterimr.github.io/RstoxUtils/reference/downloadLandings.md)
function to produce similar data.

## Usage

``` r
salesnote_example_data
```

## Format

A tibble

## Source

Norwegian Directorate of Fisheries (<https://www.fiskeridir.no/>)
