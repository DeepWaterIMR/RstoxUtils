# Prepare gear list

Wrapper for
[`prepareGearList`](https://rdrr.io/pkg/BioticExplorerServer/man/prepareGearList.html).
Uses the updated IMR reference API. See BioticExplorerServer for full
documentation.

## Usage

``` r
prepareGearList()
```

## Value

A data.table of gear codes and categories from the IMR reference API.
