# tryCatch both warnings (with value) and errors

tryCatch both warnings (with value) and errors

## Usage

``` r
tryCatchWE(expr)
```

## Arguments

- expr:

  an R expression to evaluate

## Value

List of logicals indicating whether the `expr` produces a warning or
error.
