# Prepare cruise series list

Wrapper for
[`prepareCruiseSeriesList`](https://rdrr.io/pkg/BioticExplorerServer/man/prepareCruiseSeriesList.html).
Uses the updated IMR reference API. See BioticExplorerServer for full
documentation.

## Usage

``` r
prepareCruiseSeriesList()
```

## Value

A data.table of cruise series metadata from the IMR reference API.
