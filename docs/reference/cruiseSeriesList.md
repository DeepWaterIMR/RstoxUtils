# NMD/IMR cruise series list

Use the
[`prepareCruiseSeriesList`](https://rdrr.io/pkg/BioticExplorerServer/man/prepareCruiseSeriesList.html)
function to update the list. Need to be updated every time data from the
database are downloaded.

## Usage

``` r
cruiseSeriesList
```

## Format

A data table

## Source

Institute of Marine Research (<https://imr.no>)
